# 🚖 NCR Ride Booking SQL Project

This project analyzes a **ride booking dataset (NCR region)** using SQL.  
It provides insights into customer behavior, cancellations, revenue, and operational metrics.

---

## 📂 Project Files
- `ncr_ride_booking_sql_project.sql` → SQL queries covering ride trends, cancellations, customer insights, and revenues.
-  Power BI report to visualize the same analysis (coming soon).

---

## 🔍 Key SQL Analyses
- Distinct vehicle types
- Booking trends and revenues by date
- Cancellations by customers vs drivers
- Most common cancellation reasons
- Average ride distance & booking value by vehicle type
- Payment method performance (rides & revenue)
- Top 3 highest spending customers
- Driver cancellation rate
- Monthly trend of completed rides
- Peak booking hours
- Pickup–drop routes with highest revenue
- Ratings analysis (customer vs driver)

---

## 🚀 How to Use
1. Import your ride booking dataset into a SQL database.
2. Run the queries from `ncr_ride_booking_sql_project.sql`.
3. Explore the insights generated.
